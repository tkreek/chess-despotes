# Stockfish engine

`stockfish-19-lite-single.js` / `.wasm` are the single-threaded "lite" WebAssembly build of
[Stockfish](https://stockfishchess.org/) 19 from [Stockfish.js](https://github.com/nmrugg/stockfish.js)
(npm package `stockfish@19.0.1`), copied unmodified.
